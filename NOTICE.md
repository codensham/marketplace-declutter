# Data sources

`data/places.json` is generated by `scripts/build-places.mjs` from:

- **GeoNames postal codes (US)** — https://download.geonames.org/export/zip/ —
  licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Postal city names and coordinates; each city's point is the mean of its ZIP
  code centroids.
- **US Census Bureau Gazetteer files** (Places and County Subdivisions) —
  https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.html —
  public domain. Used for names that are not postal cities.

To regenerate, download the files into `scripts/raw/` and run:

```
node scripts/build-places.mjs scripts/raw/<places>.txt scripts/raw/<cousubs>.txt scripts/raw/<geonames US.txt>
```

`data/aliases.json` is generated by `scripts/build-aliases.mjs` from:

- **GeoNames gazetteer (US)** — https://download.geonames.org/export/dump/ —
  licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  Populated places (mostly neighborhoods and unincorporated communities) that
  `data/places.json` cannot find. Names whose places lie more than 10 miles
  apart within one state are left out as ambiguous, as are trailer parks,
  apartment complexes and subdivisions.
- `scripts/manual-aliases.json` — hand-kept additions and removals.

Build `data/places.json` first, then run:

```
node scripts/build-aliases.mjs scripts/raw/<geonames dump US.txt>
```
